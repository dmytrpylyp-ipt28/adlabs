Лабораторна робота №6
C++ openCV
дедлайн 9 травня
Хід виконання роботи
Створити C++ програму, яка в циклі:
Читає відео з камери.
Відображає його у вікні.
Реагує на натискання клавіатури та миші.
Вмикає різні режими обробки зображень в залежності від натиснутих клавіш.
Вимоги:
Використати openCV (інші бібліотеки за бажанням).
Програма має мати модульну архітектуру (кожен модуль — окремий клас в окремих файлах .hpp та .cpp).
Білд за допомогою CMake + make
Зручний білд-скрипт (build.sh), в якому будуть міститись всі необхідні команди для компіляції
Зручний скрипт попереднього встановлення (preinstall.sh), який буде містити всі команди, необхідні для білда і запуску вашої програми на іншому комп’ютері. Наприклад, встановлення бібліотек та білд системи:
$ sudo apt install libopencv-dev cmake gcc -y
Зручний скрипт запуску (run.sh), який буде запускати вашу програму
В readme.md в директорії з програмою, описати інструкції для білду і запуску, а також вимоги до операційної системи та заліза.
Записати відео з демонстрацією всього функціоналу програми та відправити викладачу
